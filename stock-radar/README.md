# 短线雷达 · 复盘工作台

基于通达信（TDX）数据能力的 A 股短线复盘 Web 系统：数据驱动的复盘计划、短线选股、实时机会与连板低吸。

## 快速开始

```bash
# 环境要求：Node.js >= 18（使用内置 fetch），无需安装任何依赖
cd stock-radar
node server.js
```

浏览器打开 <http://localhost:8787> 即可。

- 默认使用**免费实时行情**（东方财富公开接口），无需任何 Key，开箱即用
- 端口可在 `server.js` 顶部 `PORT` 常量修改（默认 8787）
- 停止服务：终端 `Ctrl+C`

## 数据模式（自动切换）

| 优先级 | 模式 | 条件 | 说明 |
|---|---|---|---|
| 1 | 官方实时 `live` | 设置页填写了通达信 API Key | 走通达信官方 MCP 服务，含 NLP 条件选股、F10 深度数据（按积分计费） |
| 2 | 免费实时 `free` | 未填 Key（默认） | 东方财富公开行情：全市场快照、涨停/跌停池、主力净流入、日 K 线、MACD 本地计算 |
| 3 | 快照兜底 `fallback` | 上述数据源均异常 | 展示 `data/snapshot.json` 历史快照 |

顶栏状态胶囊实时显示当前模式与更新时间。

### 获取官方 API Key（可选）

1. 登录通达信 VIP 商城 <https://vip.tdx.com.cn/>
2. 会员中心 → 通达信 Key 管理 → 创建 Key，勾选"通达信数据服务"
3. 在 Key 详情中复制，粘贴到网页右上角 ⚙ 设置弹窗保存（可先"测试连接"）

## 功能一览

- **复盘中心**：四大指数实时行情（含 5 日/20 日/年初至今涨幅）、题材热度聚合、连板天梯、情绪周期判定（启动/发酵/高潮/退潮/冰点）、六步复盘计划、涨停池（含流通市值）、跌停与风险
- **短线精选**：涨停龙头 / 主力进攻（主力净流入排行）/ 技术金叉（MACD 金叉+放量，本地计算）/ 异动蓄势（量比≥2 且涨幅 3~6%）
- **实时机会**：快速拉升（涨幅≥5%）/ 涨停前线（按最新封板排序）/ 资金抢筹
- **连板低吸**：上一交易日 2 连板及以上、今日回调（涨幅 ≤2% 且未接近跌停）的低吸标的，自动回溯最近交易日
- **AI 推荐**：聚合涨停池 / 主力净流入 / MACD 金叉 / 异动蓄势 / 连板低吸等多源信号，多因子打分（信号共振、连板高度、封单强度、资金流、5 日线乖离、题材热度、情绪周期），输出评分 Top 12 个股卡片（亮点 / 风险 / 操作建议）。在设置中配置 OpenAI 兼容大模型（Base URL + Model + API Key）后，由大模型生成深度分析文本；未配置时自动使用本地规则引擎。盘前/非交易时段自动回退到最近交易日涨停池 + 最新报价分析
- **全局能力**：板块筛选（全部/主板/创业板/科创板/北交所）、30 秒自动刷新（可开关、可手动立即刷新）、个股抽屉（实时报价 + 120 日 K 线蜡烛图 + 主力净流入）

## 项目结构

```
stock-radar/
├── server.js           # 后端：零依赖 Node HTTP 服务（端口 8787）
│                       #   - 官方 MCP 客户端（JSON-RPC over HTTP，需 Key）
│                       #   - 免费行情数据层（东方财富接口，无需 Key）
│                       #   - 数据加工：涨停池规整、题材聚合、情绪周期、复盘计划推导
├── public/
│   ├── index.html      # 页面结构（四个标签页 + 个股抽屉 + 设置弹窗）
│   ├── style.css       # 深色交易终端风格样式
│   └── app.js          # 前端逻辑（渲染、板块筛选、自动刷新、ECharts K 线）
├── data/
│   ├── config.json     # API Key 配置（设置页保存，勿提交到仓库）
│   └── snapshot.json   # 快照兜底数据
├── gen-snapshot.js     # 快照生成脚本（可选，见下）
└── manifest.json       # 快照生成的原始数据文件映射
```

## 主要 HTTP 接口

| 接口 | 说明 |
|---|---|
| `GET /api/status` | 当前数据模式、快照时间 |
| `GET /api/review` | 复盘中心数据（指数/题材/涨停池/情绪/计划） |
| `GET /api/picks` | 短线精选（四策略） |
| `GET /api/realtime` | 实时机会（三通道） |
| `GET /api/lbdip` | 连板低吸 |
| `GET /api/ai-picks` | AI 短线推荐（多因子评分 + 规则/大模型分析，`data.engine` 标识 `rule`/`llm`） |
| `GET /api/stock?code=600519` | 个股详情（报价 + 日 K + 资金） |
| `GET /api/config` | 读取配置状态（不回传 Key 本体）；`POST /api/config` 保存通达信 Key 与大模型配置；`POST /api/config/test` 测试通达信 Key |

任意数据接口加 `?snapshot=1` 可强制返回快照数据。响应统一包络：`{ mode, generatedAt, data, error? }`。

## 缓存与刷新策略

- 前端：全局 30 秒倒计时自动刷新当前标签页（子工具栏可开关）
- 后端内存缓存（避免频繁请求上游）：实时机会 15~20 秒、复盘/精选 30~60 秒、历史涨停池 5 分钟、指数区间涨幅 10 分钟、日 K 线 60 秒

## 免费行情源容灾

东方财富公开接口存在**按节点限流**（连接被重置 `UND_ERR_SOCKET`，通常数秒后自动恢复）。为避免页面整块降级为快照数据，行情层做了四层保护：

1. **多主机轮询**：`/api/qt/*` 接口在 `push2 / 1.push2 / 7.push2 / push2his / push2delay` 五个节点间自动切换（限流通常只影响部分节点）
2. **指数退避重试**：网络层错误最多重试 5 次，间隔 200→1000ms，等待限流窗口释放
3. **全局限流**：后端最多 3 并发、相邻请求间隔 ≥80ms，从源头降低触发风控概率
4. **局部降级 + 备用源**：单个策略/通道失败不影响整页渲染；日 K 在东财全部节点失败时自动改用腾讯 `web.ifzq.gtimg.cn` 日 K

```bash
# 若持续出现「暂展示快照数据」，可先确认是否为本机网络/代理问题：
curl -s "https://push2.eastmoney.com/api/qt/ulist.np/get?fltt=2&fields=f2,f12&secids=1.000001"
```

## 快照生成（可选维护）

无 Key 且免费源不可用时的兜底数据可重新生成（需先在 Trae 中通过 TDX 插件采集原始 MCP 输出并按 `manifest.json` 放置）：

```bash
node gen-snapshot.js
```
